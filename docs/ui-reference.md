# 暗黑文字 RPG UI 参考

## 文档用途

后续调整 Legend World 界面时，以本文记录的布局和视觉风格为参考。参考来源为用户提供的 `dark_text_rpg_ui.tsx`，原始位置：`/Users/pengchaoqun/Downloads/dark_text_rpg_ui.tsx`。

用户已确认：主要参考布局与 UI。原型中的角色数值、地图数据、战斗、移动、采集、技能和奖励逻辑不作为项目业务规则。本文记录的是目标设计参考，不代表当前页面已经实现。

## 整体风格

- 深灰黑背景、低饱和面板、细边框、小圆角，形成紧凑的文字游戏工作台。
- 金色用于主要强调、当前选中项和玩家身份；红、绿、紫承担明确的实体及状态语义。
- 以文字、数值、细进度条和小图标组织信息，地图采用文字网格的表现形式。
- 等宽字体突出文字 RPG 氛围，正文保持清楚易读，长说明允许换行。
- 面板常驻呈现核心信息，通过局部滚动和折叠控制页面长度。

## 布局与响应式

### 桌面端

顶部为常驻状态栏，下方主区域居中，最大宽度约 1280px。主区域采用 12 栏网格，按 3 : 6 : 3 分配，面板间距约 16px。

```text
┌──────────────────────────────────────────────────────────┐
│ 角色名称 / 等级 / 职业              生命 / 魔法 / 经验     │
├─────────────┬──────────────────────────┬─────────────────┤
│ 角色属性    │ 地图标题 / 位置          │ 背包            │
│ 装备槽位    │                          │                 │
│             │       文字网格地图       │ 技能            │
│             │                          │                 │
│             ├──────────────────────────┤ 附近实体列表    │
│             │ 选中目标 / 可用操作      │                 │
│             ├──────────────────────────┤                 │
│             │ 游戏日志                 │                 │
└─────────────┴──────────────────────────┴─────────────────┘
```

左栏角色信息、中央主要游戏区域、右栏背包和技能构成稳定的信息层级。项目现有的成长、怪物详情、挂机控制及待领取物品等内容需要保留，具体归位在实际改版时结合业务确定。

### 移动端

原型在 `lg` 断点切换桌面布局，按默认 Tailwind 配置约为 1024px；较窄屏幕采用单栏与底部导航。

- 底部导航包含地图、角色、背包、技能、日志五个入口，图标配短文字，当前入口使用金色。
- 角色、背包、技能按入口切换显示；地图入口显示地图、目标操作和日志。
- 原型的日志入口仍显示地图和目标操作，并展开日志，尚不是独立全屏日志页。
- 顶部状态栏允许换行，小屏时生命、魔法和经验另占一行。
- 内容底部预留导航高度，底栏适配安全区域，避免遮挡内容。

## 配色参考

以下色值取自原型的 CSS 变量，可作为项目原生 CSS 的主题参考。

| 用途 | 原型变量 | 色值 |
| --- | --- | --- |
| 页面底色 | `--bg-primary` | `#0D0F12` |
| 面板底色 | `--bg-secondary` | `#16191F` |
| 悬停底色 | `--bg-hover` | `#252A33` |
| 边框 | `--border-color` | `#343A45` |
| 主文字 | `--text-primary` | `#E5E7EB` |
| 次要文字 | `--text-secondary` | `#8B929E` |
| 玩家、主要强调、NPC | `--color-primary` | `#C6A56B` |
| 怪物、危险 | `--color-danger` | `#D76A6A` |
| 资源、正向状态 | `--color-success` | `#79B99A` |
| 稀有、魔法 | `--color-magic` | `#B69AE0` |

原型同时使用 Tailwind 的红、琥珀、绿和紫色绘制按钮及进度条，因此各处实际颜色并非全部来自上述变量。落地时统一使用项目主题定义，并保证次要文字在深色背景上可读。物品品质的颜色映射沿用项目已有品质体系，不根据原型减少或更改品质种类。

## 组件参考

| 区域 | 布局与表现 |
| --- | --- |
| 顶部状态栏 | 吸顶；左侧名称、等级和职业；右侧生命、魔法、经验细条及数值 |
| 通用面板 | 深灰底、1px 边框、约 6px 圆角、12～16px 内边距；标题区用细分隔线区分内容 |
| 角色面板 | 属性与装备使用局部页签；属性以标签和值对齐，装备以槽位和物品名称成行展示 |
| 地图 | 居中正方形网格，原型实际为 6×6、最大宽度约 460px；格间距约 4～6px；格子以实体名称为主 |
| 地图实体 | 玩家金色并带描边，怪物红色，资源绿色，稀有物紫色，空格弱化；有生命的实体底部显示微型状态条 |
| 选中目标 | 地图格子金色边框和轻微光晕；地图下方面板展示名称、等级、状态和当前可用操作 |
| 背包 | 紧凑列表，名称左对齐、数量右对齐；选中后在面板下方显示说明与操作 |
| 技能 | 名称、等级、效果、消耗分层排列；右侧操作按钮；不可用状态降低强调 |
| 实体列表 | 桌面辅助入口，名称和坐标分列；选中态与地图一致 |
| 日志 | 时间与正文分列；默认显示最近三条，可展开历史并滚动；新日志自动滚到底部 |

原型地图注释写作 8×8，但数据和网格样式均为 6×6。此处仅记录实际视觉参考，项目地图尺寸由后续需求决定。

## 字号、间距与操作反馈

- 主体信息约 12～14px，辅助信息约 10～11px，重要名称约 14～16px；这些是原型尺寸参考，落地时兼顾阅读体验。
- 按钮使用低饱和语义底色与细边框：攻击偏红、技能偏紫、采集偏绿、对话偏金。
- 选中态使用金色边框和浅色背景；悬停时轻微提亮，避免大面积高亮。
- 原型以 150～300ms 的短过渡表现选中、悬停及进度变化。
- 移动端主要可点击区域参考至少 44×44px；原型部分小按钮尚未达到该尺寸，不能直接视为已满足触控要求。
- 日志通过颜色区分伤害、怪物攻击、恢复和奖励，同时保留明确文字说明。

## 与当前项目结合的约定

1. 继续使用项目的 React、TypeScript、Zustand 和原生 CSS。参考文件使用 Tailwind 与 `lucide-react`，不因此直接引入这些依赖。
2. 展示数据和操作复用 `src/game/panels/` 与 `src/stores/gameStore.ts`，遵守 `src/core/` 的业务契约。
3. 挂机、成长、技能学习、装备限制、背包堆叠、奖励及待领取等行为继续使用项目现有实现。
4. 文字地图、实体交互及五入口导航是设计参考；尚未实现的移动、采集、NPC 等功能需另有明确需求再接入。
5. 原型的硬编码状态、随机伤害及奖励计算不移植到项目，也不作为修改核心规则的依据。

## 后续改版时的对照项

- 桌面是否形成清晰的左侧角色、中央主玩法、右侧物品与技能三栏层级。
- 移动端入口是否清楚，主要操作是否易点，底部导航是否遮挡内容。
- 深色背景、面板边框、金色选中态及语义颜色是否一致。
- 属性、物品、技能和日志是否紧凑且可读。
- 现有业务功能及数据来源是否完整保留。

本文作为后续设计与开发的参考入口；具体实施范围以当次用户需求为准。
