# 传奇世界 · Legend World

独立的 Web 游戏项目，参考爱可小镇的技术栈创建，不依赖爱可小镇的源码或运行环境。

## 技术栈

React 19、TypeScript 7、Vite 8、PixiJS 8、Zustand 5、原生 CSS，使用 pnpm 10.26.2 管理依赖。依赖版本与创建时的参考项目保持一致，锁文件一并复用。Zustand 仓库负责战斗展示快照及基础信息面板状态。

## 开发

Node.js 要求：`^22.12.0 || >=24.0.0`。

```sh
cd /Users/pengchaoqun/code/legend-world
pnpm install
pnpm dev
```

同一时间运行多个 Vite 项目时，以终端实际输出的端口访问。

## 当前范围

已创建独立工程配置、React 入口与 PixiJS 场景模块；当前首页采用暗黑文字 RPG 工作台：桌面左侧角色与装备、中间文字战场及日志、右侧背包与技能；窄屏通过底部导航切换战场、角色、背包、技能和日志。文字战场展示当前交战双方，不提供地图移动。

已接入现有核心模型，使用本地配置创建一名 1 级战士「初行者」和一只 1 级普通怪物「野狼」。页面属性卡展示名称、等级、生命、魔法及最终战斗属性。配置位于 `src/game/data/localWorld.ts`，刷新页面重新创建单位，尚未接入存档或联网。

点击「开始挂机」持续自动交战：第 1 秒开始，双方每秒行动、角色先手。战士优先释放重击（本次攻击 +6、耗魔 5），按本地技能配置的顺序与冷却尝试技能，不可用时普通攻击。普攻与重击统一按最终攻击减最终防御计算，伤害最低为 0。野狼优先使用撕咬（本次物攻 +4、耗魔 0、冷却 3 秒，初始可用），冷却时普通攻击；双方共用技能优先级、命中及伤害规则。页面显示血条、实际扣血数字、技能提示和战斗日志。命中率只读取攻击方最终属性，限制在 0%～100%，当前角色和野狼均为 100%，暂不计算闪避和暴击。普攻及物理技能判定命中，技能一次释放共用一次判定；未命中不扣血，仍耗蓝、进入冷却并占用行动。固定伤害、治疗和回蓝不判命中。属性面板显示命中率，伤害提示、最新行动和日志区分未命中与命中但零伤害。

击败野狼一次性获得 20 经验，并对每条掉落独立判定：狼牙 100%、木剑 30%、精铁剑 10%，每条命中获得 1 件，可以不掉装备。物品按核心堆叠规则进入背包，满包剩余掉落进入待领取列表；战败不发奖。经验按等级表结算，支持连续升级，升级回满生命和魔法。战士最高 60 级，L 级升级消耗 20 × L 经验，每级生命 +12、魔法 +2、物攻 +2、物防 +1。角色成长面板展示升级进度与下一级属性增量，战斗日志记录本次升级。胜利后完整等待 2 秒创建全新野狼实例，角色成长、装备、背包和当前生命 / 魔法跨场保留，每场技能冷却重新开始；战后不额外恢复资源，升级仍按最终上限回满。页面展示当前阶段、场次、击杀数和等待倒计时，战利品摘要只显示最近一场，背包累计真实掉落。

点击「停止挂机」会打完当前场、结算一次后停止；等待中停止立即生效，保留剩余等待，再次开始继续倒计时，不能跳过胜后两秒。没有中途暂停战斗功能。死亡无额外经验或物品惩罚并停止挂机，点击复活按最终上限回满生命和魔法，之后需手动开始新场。战斗中包括「本场后停止」阶段禁止学习，战后等待或停止且不在战斗时可学习。刷新页面仍重置角色和背包，没有存档。

核心 CombatSession 保持单场纯逻辑，IdleCombatSession 协调连续战斗、等待、刷新、停止和复活，均只接受累计逻辑毫秒。新怪物与掉落 ID 按场次区分，日志使用跨场时间及唯一 ID。长推进遇到停止 / 死亡停在真实结算点；浏览器计时由 `src/stores/gameStore.ts` 中的宿主适配层提供，每次手动开始从核心实际停点建立新时钟段，停止期间的墙钟不会补算为行动或刷新。React 只连接生命周期与展示快照。

职业技能目录与已学记录分开保存。战士初始只学会重击，3 级可学强力一击、5 级可学自我治疗、8 级可学汲取打击；达到等级后在面板手动学习，不消耗经验、物品或金币。战斗中禁止学习，由核心校验和页面按钮同时约束，战斗结束后解除限制。只有已学技能能参与战斗，释放优先级沿用目录顺序；直接向战斗传入未学技能也会失败，且不扣魔法、不启动冷却。当前所有技能学习后默认为 1 级，面板显示已学技能等级、学习条件、效果、耗蓝、当前配置冷却和学习状态。技能升级与多等级效果按当前要求暂缓。战士另有 1 级被动「强健体魄」，在非战斗状态免费手动学习，生命上限 +20，不恢复当前生命；被动加成与等级、装备统一汇总，查询不重复叠加。面板标明被动，不显示释放优先级、耗蓝或冷却，被动不参与主动释放和行动选择。

角色与怪物基础信息常驻展示。角色展示职业、等级、累计经验、生命、魔法和战斗属性；怪物展示实例及种类 ID、品级、等级、生命、魔法、战斗属性、技能优先级、技能耗魔/冷却/效果、击杀经验及独立掉落概率。面板读取与战斗相同的单位实例，战斗与背包操作后同步更新；查询不会修改单位或发放奖励。

背包固定 30 格：装备每件 1 格且保留独立实例，材料每格最多 99 个，药水每格最多 20 瓶。页面按实际堆叠格子展示并支持分类、穿戴、丢弃；丢弃前确认数量。初始提供装备、材料及 5 瓶小生命药水。小生命药水恢复 50 生命，仅存活且未满血可用，恢复不超过生命上限，成功后消耗一瓶，战斗中也可使用。满包经验照常发放，未入包掉落保留待领取，腾出空间后手动领取，可分次领取。

装备支持当前六个部位的穿戴、替换和卸下，战斗中可操作。换装转移原装备实例，属性立即生效；穿脱不恢复资源，上限降低时压回新上限。满包卸装会保留原装备并提示腾出一格。穿戴检查统一读取装备等级与职业条件：精铁剑需要 2 级，其他初始装备需要 1 级，初始装备均不限职业。换装及用药前先结算操作时刻及之前的行动，后续行动才使用新状态。额外槽位尚未实现。

掉落装备创建时独立生成品质：普通 70%、优秀 20%、稀有 8%、史诗 2%，品质当前只作标识，不影响基础属性。另一独立方法以 20% 概率生成一项极品：物攻或物防等概率选择，+1～3 均匀取值。基础属性、穿戴条件来自定义，额外属性单独保存在实例并汇总到角色最终属性。背包、装备栏与待领取列表分别展示基础和极品加成；初始赠送装备保留预设品质且没有随机极品。查询、穿脱、领取均不重抽。

核心 `RandomSource` 返回 [0, 1)；`CombatSession(character, monster, random)` 必须接收随机源，核心不调用 Math.random。`createGameStore(world, now, random)` 由宿主提供时钟与随机源（默认逻辑时钟为 0，默认随机源为 Math.random），App 显式传入 performance.now 与 Math.random。战斗命中与掉落共用该随机源：非确定命中概率每次攻击或物理技能释放消耗一次随机值，0% 与 100% 不抽取。掉落按表顺序判定，每条先消耗一次掉落随机值；命中装备再消耗一次品质值和一次极品判定值，命中极品后再消耗属性、数值各一次。测试注入有限序列以确定结果，长短时间推进消耗顺序一致。

`src/game/panels/` 负责整理信息与背包快照，`src/stores/gameStore.ts` 负责战斗推进、背包操作与状态同步。组件展示快照和调用操作，后续替换 UI 可以复用这两层逻辑。核心保持独立，不依赖 UI、浏览器或真实时钟。

页面尚未接入移动、任务、存档、联网或离线挂机。不复用爱可小镇的宠物或生命模型。
