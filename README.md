# 传奇世界 · Legend World

独立的 Web 游戏项目，参考爱可小镇的技术栈创建，不依赖爱可小镇的源码或运行环境。

## 技术栈

React 19、TypeScript 7、Vite 8、PixiJS 8、Zustand 5、原生 CSS，使用 pnpm 10.26.2 管理依赖。依赖版本与创建时的参考项目保持一致，锁文件一并复用。Zustand 已声明依赖，尚未创建业务状态仓库。

## 开发

Node.js 要求：`^22.12.0 || >=24.0.0`。

```sh
cd /Users/pengchaoqun/code/legend-world
pnpm install
pnpm dev
```

同一时间运行多个 Vite 项目时，以终端实际输出的端口访问。

## 当前范围

已创建独立工程配置、React 入口、PixiJS 生命周期、响应式画布和月夜群山石门初始场景。场景使用本地矢量绘图，无外部图片依赖。支持卸载清理、异步初始化取消和设备像素比更新。

已接入现有核心模型，使用本地配置创建一名 1 级战士「初行者」和一只 1 级普通怪物「野狼」。场景显示单位的矢量形象、名称和等级，页面属性卡展示生命、魔法及基础战斗属性。配置位于 `src/game/data/localWorld.ts`，刷新页面重新创建单位，尚未接入存档或联网。

点击「开始战斗」进入一场自动交战：第 1 秒开始，双方每秒行动、角色先手。战士优先释放重击（本次攻击 +6、耗魔 5、冷却 3 秒），不可用时普通攻击。普攻与重击统一按最终攻击减最终防御计算，伤害最低为 0。页面显示血条、实际扣血数字、技能提示和战斗日志。

击败野狼一次性获得 20 经验和 1 件「狼牙」，物品实例保存在角色的已获得列表中；战败不发奖。经验暂时只累计，不触发升级。单场结束后停止，不自动续战，刷新页面重新开始。核心 CombatSession 仅接收外部逻辑时间，浏览器计时留在 React 界面。

页面尚未接入移动、任务、完整背包或装备穿戴。不复用爱可小镇的宠物或生命模型。

## 目录

```text
src/
├── app/                 # React 界面组合
├── components/          # 游戏画布宿主
├── game/
│   ├── Game.ts          # 初始化、缩放与销毁
│   ├── data/            # 本地角色与怪物初始配置
│   └── scenes/          # 初始世界场景和美术配置
├── core/                # 角色、怪物与战斗等核心模型
├── stores/              # 后续 Zustand 业务状态
├── styles/              # DOM 样式
└── main.tsx             # 应用入口
```
